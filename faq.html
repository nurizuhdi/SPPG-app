FAQ

Terakhir diperbarui: · Penyedia layanan:

Jawaban cepat untuk pertanyaan yang sering muncul.

Berapa lama trial gratis?

30 hari sejak Admin mendaftar. Setelah itu perlu berlangganan agar akses tetap terbuka.

Berapa biaya langganan?

untuk 30 hari, dibayar lewat Midtrans. Perpanjangan manual, tidak ada tagihan otomatis.

Apa itu kode lisensi?

Kode satu kali pakai untuk mengaktifkan aplikasi di satu perangkat. Layar aktivasi muncul pertama kali sebelum login. Kode didapat dari penyedia aplikasi.

Apa itu Kode Workspace?

Kode ruang data milik Admin Anda. Operator memerlukannya (selain nama dan password) untuk masuk. Kode tampil di menu Pengaturan Admin dan sudah terisi otomatis lewat tautan yang dibagikan Admin.

Bagaimana menambah Operator?

Admin buka Kelola Operator, isi nama dan password, lalu bagikan tautan yang muncul. Operator mengaktifkan perangkatnya dengan lisensinya sendiri, lalu login.

Saya lupa password Admin.

Di layar login Admin klik “Lupa password?”, isi email yang sama, masukkan kode OTP dari email, lalu buat password baru.

Saya lupa password Operator.

Minta Admin membuka Kelola Operator dan mengganti password Operator tersebut.

Kode OTP tidak masuk ke email.

Cek folder spam. Pastikan email benar, tunggu beberapa menit, lalu coba kirim ulang. Jika tetap gagal, hubungi kami.

Apakah data saya terlihat Admin lain?

Tidak. Setiap Admin punya workspace terpisah dan pemisahannya dijaga di database.

Ke mana foto barang masuk disimpan?

Ke galeri perangkat Anda. Foto tidak diunggah ke server.

Apa yang terjadi bila langganan berakhir?

Akses dikunci untuk Admin dan Operator. Data tidak dihapus dan bisa dipakai lagi setelah langganan diperpanjang.

Bisa minta refund?

Hanya pada kondisi tertentu; lihat Kebijakan Refund.

Bagaimana menghubungi dukungan?

Lewat email atau WhatsApp di bagian bawah halaman ini.
